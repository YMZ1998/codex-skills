# git-commit

`git-commit` 是一个本地 Git 提交技能，用于分析当前改动、选择提交范围并生成简体中文提交信息。它只创建本地提交，不会执行 `push`。

## 提交范围

- 存在已暂存文件时，只提交已暂存内容，不再执行任何 `git add`。
- 没有已暂存文件时，执行 `git add -u`，暂存所有已追踪文件的修改和删除。
- 未追踪文件不会被自动加入提交。
- 没有可提交内容时停止，不创建空提交。

## 提交信息

首行格式：

```text
<类型>: <一句话概述>
```

类型包括 `feat`、`fix`、`docs`、`style`、`refactor`、`test` 和 `chore`。改动较多时，可以空一行后用 `-` 列出要点。末尾固定追加：

```text
Commit-By: Codex, GPT-5
```

## 使用

```text
使用 $git-commit 提交当前改动
```

补充说明会作为提交信息的参考：

```text
使用 $git-commit 提交当前改动，补充说明：整理技能安装文档
```

## 安全边界

技能不会执行 `git push`、`git commit --amend`、新建分支或切换分支。仓库存在未解决冲突或正在进行 merge/rebase 时，它会停止并提示先处理仓库状态。
